HIIRAGI HITSUGI / Twitch latest archive setup

Node.js不要の
Twitch連携セットアップ

Cloudflareのブラウザ管理画面だけで設定できます。Client IDはコードへ設定済みです。Client SecretはCloudflareのSecret欄にだけ入力してください。

重要： Client SecretはGitHub、サイトのJavaScript、このチャットへ貼らないでください。
1

CloudflareでWorkerを作成

  1. Cloudflare Dashboardを開く
  2. Workers & Pages → Create application
  3. Create Worker → Deploy
  4. 作成したWorkerでコード編集画面を開く
Cloudflare Dashboardを開く
2

Workerコードを貼り付け

既存コードをすべて削除し、下のコードへ置き換えてデプロイします。

3

Client Secretを登録

  1. Workerの Settings を開く
  2. Variables and Secrets → Add
  3. Typeを Secret にする
  4. Nameに TWITCH_CLIENT_SECRET
  5. ValueにTwitchで発行したClient Secret
  6. 保存後、再デプロイ

Client ID y1xa5t8h43ygyd6ygmi4fgsg0i162q はWorkerコードへ設定済みです。

4

APIをテスト

Workerに表示される https://◯◯.workers.dev を開き、末尾に次を付けます。

/latest?channel=hiragi_hitsugi

"ok": true が返れば成功です。

5

サイト設定を生成

コピーした内容で js/media-config.js を丸ごと置き換え、GitHubへアップロードしてください。
